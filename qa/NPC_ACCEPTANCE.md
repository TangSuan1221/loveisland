# NPC 系统独立验收

日期：2026-11-12。审查者为独立研究子agent，未修改游戏实现源码；审查源码、运行纯逻辑测试，并对照 `NPC_RESEARCH.md` 的官方证据。浏览器画面与真人连续游玩不在本报告的已验证范围。

## 结论

本轮已从各自循环散步推进到真实的需求驱动活动、双方邀请与拒绝、分阶段互动、双向关系、话题学习、礼物喜好和存档恢复。它是有因果与持续状态的原创NPC原型，不能称为《朋友收集 梦想生活》完整1:1还原。

## 独立实测

执行 `node qa/npc-independent-review.mjs`，实际结果在 `npc-independent-results.json`，含源码SHA256。脚本固定种子20261112，推进1800个模拟秒；这是加速逻辑测试，不是30分钟真人游玩。

最终站位修复版复测（源码SHA256 `7a90a5e119e6151f81feb119a699a8eaa9f2b37bf0cedaa01bcef0f661825405`）：30次互动完成、18次邀请被拒绝，共48次邀请；7种日常活动与5种社交类别产生，包含1次争执和1次道歉。中途保存、恢复并继续执行后，完整序列化状态相同；没有检测到非有限人物坐标。已独立校验最终构建 `index-l3A9XWrg.js` 的SHA256为 `6B46FB46EC3A3C4F5BECB99386C8D754F8BA1D71C43123C36F2D753C3D58B479`。

首轮历史问题：第40.3模拟秒，周屿进食与陈野待机占据完全相同坐标；全段记录719个人物对采样距离小于0.25单位。修订增加离开设施过程与局部分离后，最终版完整复跑最近距离为0.620017405单位，低于0.25的采样为0。**本次重叠复现已修复。**后续浏览器又发现对话人物过近，故不能只用0.62的通行距离作为交谈距离门槛：最终目标容差改为0.12、中间点保持0.72，已到场社交人物由路人避让。独立记录5430个已到场会话采样，最近距离1.499058977单位。逻辑距离仍不等于动画肢体永不交叠。

另外独立执行最终实现者测试 `node qa/npc-simulation.test.mjs`，6个种子各1800模拟秒均PASS，完成29–32次互动，拒绝17–35次，逐步最小距离约0.62，已到场会话最近距离为1.481–1.509。种子7和1937未出现道歉，不声称所有种子都覆盖所有事件。测试包括正常存档恢复、话题进入对话、资源约束、扩区活动、旧坐标/旧会话迁移和时间步长一致性。没有由此宣称原作频率等价或任意存档绝对安全。

## 已核实的实现与局限

| 子系统 | 核实的实际作用 | 限制 |
|---|---|---|
| 需求 | 饥饿、疲倦、社交、娱乐影响活动分数；高需求影响接受邀请 | `energy`实际是疲倦程度，不是剩余精力；没有完整作息或离线模拟 |
| 性格 | 社交倾向影响邀约、活力影响速度、直接程度影响冲突、善意影响结果；新增16种原创阈值分类，quirk与quirkiness实际影响待机/步态 | 当前6位固定配置，不是原版16类映射；分类标签本身不另加决策规则，没有完整性格/习惯编辑器 |
| 兴趣 | 音乐/阅读提高相应活动权重；共同兴趣影响话题与分享；礼物反应有差别 | 兴趣库小、偏好仅两档，没有完整物品库 |
| 互动 | 双方忙闲检查、拒绝、接近、4个对话阶段、结束结算 | 全局同时只有一个会话，固定中心会面位置 |
| 关系 | A→B与B→A分开存；亲近影响选人和回应，信任影响邀请与和好概率，熟悉度决定初识台词；冷却实际参与 | 熟悉度当前影响对话内容，不是完整活动决策因子；双方每次变化同正负、幅度略不同；远未覆盖复杂误会与恋爱网络 |
| 记忆 | 有限记录保留并显示，存档保存；已教话题影响以后对话；再次交谈引用与该人的真实上次话题，道歉可复用分歧话题 | 已有具体经历回调，不再只是装饰日志；仍是条件检索，不是完整情节记忆推理，超过容量的记忆会丢弃 |
| 物品 | 设施有owner互斥、先预约再前往；离位前保留占用，到达出口再释放；角色局部分离 | 使用固定资源点，已连通中央、北长椅与东南望台前，没有全岛动态资源/排队系统 |
| 导演镜头 | 到场后切镜，缓存对话轴侧，开场/收束中景、说话者偏近景、结束回全景；controls start取消补间并暂缓自动跟看 | 已有景别变化，不能继续称只有同一中景；仍没有遮挡求解、原作逐镜对照或完整特写镜头库 |
| 动画 | 模拟活动驱动说话、聆听、分享、争执、阅读、进食、伸展等姿态 | 程序化姿态，缺复杂表情曲线、手物接触、完整共同表演 |
| 存档 | 保存随机状态、路线、会话、关系；正常保存恢复一致 | 需继续覆盖坏ID、场景互斥和版本迁移；不能仅凭一次恢复测试宣布全面稳健 |

## UI 审查与已修复问题

初审发现UI读取 `result.message` 而引擎返回 `reason`，造成忙碌、拒绝等具体原因丢失；已看到修订读取reason。初审性格展示只有通用句、礼物没有入口、关系只有单向数字，已看到新增性格/兴趣、三类礼物和双向关系展示。需求标签改为疲惫，且解释高值代表更想满足需要。手动滚轮开始时当前cameraTween也会取消，旧补间覆盖输入的问题已修。

这些是源码核验，不代表所有控件在浏览器中已验收。请以主agent的实际交互证据补充。

## 存档缺陷复测

早期存档校验仅检查部分坐标和需求。删去 `actors[0].relationships` 仍被接受，首次后续选人抛异常，主程序仅捕获构造阶段错误，无法自动恢复。最新独立测试中，缺 relationships、personality、route 均在构造阶段抛 `Incompatible NPC save`，主程序可退回新模拟；这三项已修复。

## 通行检查

最终导航已从中央扩至北侧长椅前阅读点(-1.2,-10.3)与东南望台前赏景点(8.1,13.1)。独立默认种子实测有4692个北侧阅读人物采样和4313个东南赏景人物采样，证明不是只新增地点标签；这些是0.1秒采样数，不是活动次数。实测包围范围X[-5.240,8.537]、Z[-10.538,13.475]。北路从两排小屋之间经过，南路绕篝火东侧，仍在溪流东侧陆地上。

独立记录最近距离：彩旗柱0.460、篝火中心2.768、东南花坛中心1.127单位；按源码设施位置没有发现穿入这些主体。新增彩旗柱排斥修复旧中心节点靠柱过近的问题。此检查是固定路线和代表障碍的几何间距验证，不是全岛完整碰撞检测，也不验证摆臂与小花等装饰永不穿插。

## 尚未达到1:1的明确清单

- 原作16性格的逐类行为映射、独立小习惯编辑与完整表现；新增16原创分类及6个表现习惯属于局部推进，不等于原作覆盖。
- 全岛自由行动、多场所相遇、多组并行互动、8人同住。
- 恋爱偏好、告白、拒绝后长期状态、三角关系、婚姻与家庭。
- 大规模原创事件与台词库、多事件因果回忆、复杂礼物与喜恶；当前已经能引用同伴上次话题，但没有长篇经历链。
- 现实时间同步、离线结算、昼夜作息、完整岛屿生活循环。
- 对照原作版本和实机样本统计的触发频率、时长、关系变化分布。

“达到可继续开发的社交原型”与“还原原作全部AI”是两个验收结果；后者当前不通过。
