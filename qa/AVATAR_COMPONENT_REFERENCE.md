# 角色组件参考核查与映射

核查日期：2026-11-12。对应作品为《Tomodachi Life: Living the Dream》（朋友收集／梦想生活），而非 3DS 旧作。本表用于确定原创组件的覆盖范围；数量接近不等于美术品质、组合质量、动画或整体功能达到原作。没有复制其模型、贴图或 UI 素材。

## 来源与证据等级

1. **官方设计确认**：[Nintendo 开发者访谈第 2 章，2026-04-15](https://www.nintendo.com/au/news-and-articles/ask-the-developer-vol-21-tomodachi-life-living-the-dream-chapter-2/)。确认可调睫毛、眼褶及嘴部角度，双色头发，独立部位颜色与自由面绘。该页没有完整组件数量表。
2. **发售后媒体观察**：[SimsCommunity 对照图表，2026-05-27](https://simscommunity.info/2026/05/27/tomodachi-mii-maker-improvements/)。直接报告 83 刘海与 111 后发，介绍前后发搭配及副色、耳朵、细分五官装饰。其“新增”列不是组件总数，不能直接作为总量。
3. **社区实机录像计数**：[Standard_Ad7506 的汇总与后续更新](https://www.reddit.com/r/tomodachilife/comments/1s33bxb/hello_there/)。给出下表数量；作者在评论中说明看过余下日文实机菜单后，将整套发型更新为 250、后发更新为 111。我们读取了其文字和链接，未逐帧独立复数全部菜单，因此仍标为社区计数，而不是“官方精确数量”。
4. **较早推算，仅交叉参考**：[ZachHasArrived 的预告菜单估算，2026-02-04](https://www.reddit.com/r/tomodachilife/comments/1qvrnl8/ive_figured_out_the_number_of_facial_options_in/)。利用滚动条比例估计范围，不能用旧区间覆盖较晚实机计数。

## 验收边界

- 列表中的每项必须进入共享 WebGPU 模型生成器；编辑器、角色头像、场景角色使用相同形象参数。
- 新选项需要存在真实几何／材质差异。只增加名称、图标、别名，或只改变微小隐藏参数，不能算已补齐组件。
- 对同类选项进行模型数据去重，再用正面、四分之三侧面、侧面和背面图检查实际可见差异。几何哈希不同不保证人眼可区分。
- 选择跨度较大的脸型、发型、五官、耳朵与眼镜交叉验证；测试旧存档、导入导出、撤销重做、照片建议和动画兼容。
- 数百项菜单需要分类、搜索或分页，且显示选中项，不能以不可检索的长列表代替可用性。
- 原创卡通风格保持一致。无限角色是创作目标，不是可验证的绝对承诺；特殊非人形轮廓、精密服饰和任意 IP 造型仍受组件及彩绘表达能力约束。

实施后的实际数量与独立审查结果另记在验收记录中；本文件的“实施前”列固定为改动前基线。

## 本轮独立验收（2026-11-12）

实际目录（排除 auto 沿用控制、包含 none 隐藏项）：脸型 16，前发 97，后发 115，眉型 43，眼型 76，鼻型 32，嘴型 53，眼镜 58，耳型 10；上睫 6／下睫 2，上眼褶 3／下眼褶 3，高光 10，上纹 9／下纹 15，胡茬 15／短髭 16／胡须 14。保留旧整套发型 18，不将前后发搭配数冒称成新增整套发型数。前后发目录含同一轮廓族的长短、宽窄和偏斜变体，不能说成每项都是独立美术原型。

独立脚本 `qa/avatar-catalog.test.mjs`：28 项通过。逐项生成实际人物模型，以可见网格的世界坐标、索引和材质计算签名，未发现同一目录内完全相同的渲染数据；验证有限坐标、资源 dispose 事件、111 组外观 JSON 往返、48 组跨风格／参数极值组合，以及原有演员 ID 和发型兼容。测试曾发现旧猫嘴与平嘴完全相同及独立眼部装饰未接入，修正后重新通过。

真实 Edge WebGPU 接触表使用 `qa/avatar-catalog-gallery.html`，按 field/start/limit/angle/base 参数生成。已检查前发、后发、眼型、嘴型、眼镜、耳朵、上下皱纹、高光，以及窄眼旋转加睫毛、特殊眼型加眼部细节、宽脸大眼加妆容等样本。抽检观察到形状与组合差异，页面没有 JavaScript 错误；不是对全部前后发组合逐一视觉验收。

视觉检查另发现后梳发束呈粗空心管、部分盘发可见孔隙、大眼遮住固定尺寸眼影，以及侧转脸部的硬阴影像眼罩／胡须，已交给对应实现者迭代。几何签名不同不代表美术质量与原作相同，最终交付说明应保留这一边界。
