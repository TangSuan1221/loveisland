## 结论

当前未达到商业高品质成品视觉，更不能据此宣称达到任天堂级或 3A。已有一致的奶油白／绿配色、可识别的场景主题，以及比环境远景更成熟的人物近景；这些是有效基础，但场景构图、资产丰富度、灯光层次和 UI 可读性仍有明显成品门槛差距。低多边形本身不是缺陷；问题在于重复、空旷、视觉层级不足和细节密度缺少设计。

未发现截图层面导致画面完全不可用的 P0。下列 P1 阻止高品质视觉验收通过。

## P1：雪山场景缺少主景与空间叙事

证据：大面积几乎同色的灰白雪地；中央人物和设施很小，外围树木以重复模型散布；上方山体像平滑的巨大几何块。没有能够迅速建立观看顺序的主建筑、暖色活动区或有节奏的地形层级。

修订：收紧默认场景镜头，使社交活动区成为明确中心；建立一个尺度明显大于零散道具的暖色木屋或营地设施作为主景。用雪坡、压实步道、树丛分组和岩石形成前中后景；减少等间距单棵树，至少区分幼树、老树、积雪量和方向。雪面需有受光暖白、背光冷蓝和接地阴影的细微分离，不能只整体增加饱和度。篝火和灯具应提供可见暖色焦点，但不可依赖发光掩盖布局。

复核条件：缩略图仍能一眼辨认主活动区；人物在实际游戏默认镜头下可区分；外围有疏密、遮挡和地形层次。

## P1：别墅场景更像资产展示台

证据：整块矩形地板和空白背景占据大量画面；相同盆栽沿玻璃边界重复排列；床、镜面、隔断、桌椅孤立摆放，缺少居住空间的区域联系。泳池近似一块平面青色区域，长直细线没有形成可信水体深度。墙面横向装饰占比大，但尚未成为有辨识度的建筑主景。

修订：围绕会客、休息、用餐建立三处完整的小空间，用地毯、局部顶棚或矮隔断组织，并保留连通动线。用一两组植物群替换整排等距盆栽。补充材质尺度差异：木纹方向、软装织物、玻璃边缘反射和池壁／水底过渡。泳池增加明确池沿、浅深渐变及克制的水面高光。镜头应展示别墅的空间关系，而非把整个地板尽量纳入画面。

复核条件：不看文字也能识别为可居住的高品质度假别墅，家具组合具有用途，泳池具有深度线索。

## P1：制作界面的信息在 720p 下偏小、偏淡

证据：右侧控制室记录正文、顶部阶段导航、资金下方明细和左侧说明均细小。奶油背景上的浅灰绿文字、按钮轮廓和部分状态文本对比偏弱。画面里有多组细字同时争夺阅读注意；正文对白反而只占下方小条区域。

修订：在 1280×720 实际视口直接设定字号与对比门槛，主要操作和正文至少以清晰可读的 14–16 CSS px 为起点，再以真实截图核验。缩减控制室微型英文装饰和重复辅助文字，记录采用更少条目、更大行距。阶段导航使用可辨认的活动／已完成状态；弱化项也要能读清。对白条扩大文字字号和说话人分离，避免仅靠颜色区分。小字号不要通过整体放大页面修补，需重新分配面板空间。

复核条件：原尺寸截图不放大即可读出关键状态、成本、行动结果和对白；禁用按钮与可用按钮可明确区分。

## P1：人物近景尚缺表演和接触可信度

证据：近景人物头身比例与轮廓较统一，辨识基础成立；但三名角色大致站在一圈，手臂和站姿变化有限，视线关系不够明确。当前静帧无法证明他们在交流。草地纹理密度大但变化单一；木头、围栏和服装的材料响应接近。

修订：让说话角色有明确朝向和轻微重心动作，听者使用不同的自然待机姿势；验证脚底接地和阴影，保持人物脸部不被极端高光或遮挡压住。按木材、布料、皮肤分别调粗糙度及色彩层次。减少均匀草地噪点，以活动区周边的磨损、草簇和色块组织地面。

复核条件：固定同一时刻的角色关系可被静帧读出；另须提交短视频才能判断表演质量，不能以本轮静态通过替代动画验收。

## P1：选角页仍偏通用网页卡片，角色吸引力不足

证据：卡片面积大，但头像非常小，文字字号也偏小；大量留白未转化成角色表达。三列卡片与右栏整体整齐，却使角色差异主要依靠名字和标签。底部提示条横跨卡片并遮挡调查操作附近内容。首屏第二行仅露出头像，完整角色比较需要滚动。

修订：扩大人物肖像或半身像，保留足够信息密度；把目标、关系和签约价建立清晰的视觉顺序。增加不同人物的姿势、轮廓和背景色差异，不以增加徽章替代人物表现。将全局提示放在不覆盖操作的位置，或使用预留反馈区。确认首屏卡片布局是否以三列为最佳，优先让实际决策信息和操作完整显示。

复核条件：可快速比较角色目标、关系与价格；反馈不会遮挡任意操作；角色无需阅读姓名也有辨识度。

## 雪山：局部改善，核心 P1 未解决

已改善：树木积雪从近似整圈层叠变为较不规则的雪块，露出的深绿色针叶增加了树冠内部明暗分离；背景山体轮廓有更不规则的起伏，较第一轮整齐块体稍自然。

未解决：默认构图仍将人物压成小比例，营地设施仍孤立散落；大块灰白雪地、同型树的外围排布、无明确主景和无明确路线的情况基本不变。山体仍主要靠大块平滑明暗构成，改轮廓没有解决前中后景与活动中心缺失。雪地缺少可识别的冷暖和材质变化。不能将树冠改模视为场景 P1 已修复。

下一步限定为三项：
1. 保持全岛总览可用，另设实际经营默认近景，使人物和活动设施的画面占比明显增加；提交这一实际默认镜头，不只提交展示总览。
2. 将现有帐篷、桌子、两座小亭中的至少三项围绕篝火／公共活动区组织成一个相连营地，用连续压实雪路连接入口、活动区、休息区；无需先大量新增资产。
3. 重排外围现有树木为三到四组不等密度树丛，保留至少一处开阔观景缺口；在活动区增加暖白受光与浅冷蓝阴影的分离，避免整张雪面同一灰白。

验收方式：并排查看总览和默认经营镜头；总览有明确活动中心和路径，经营镜头能直接辨识人物轮廓与互动位置。

## 别墅：区域提示改善，核心 P1 未解决

已改善：新增几块有边界的地毯／地面分区，桌椅与床区比首轮更容易被读成不同用途区域。植物叶片由近似直立圆柱变为展开叶片，植物轮廓稍丰富。这两处修改可见，不属于无效变化。

未解决：等距同款盆栽整排陈列依然明显；主要家具位置与空旷比例几乎没变，新增的地毯是区域提示，尚未构成完整生活空间。前景大面积空地和背景空白仍占很大比例。泳池的平面青色、稀疏直线水面表现未见有效改善；玻璃、软装、木材的材料差异仍不足。因此首轮“资产展示台感”P1 只能记为部分缓解。

下一步限定为三项：
1. 把左侧连续盆栽减少并重新分成两到三组，每组改变高低和朝向；用已有模型即可，不必增加整排新资产。
2. 将两组桌椅和屏风按会客／私聊用途形成相邻但有边界的空间，缩小地毯与家具之间不必要空隙；增加一个明确的主会客组合或局部顶棚，形成建筑焦点。
3. 为泳池补足可见池壁或水底深浅梯度、明确池沿厚度及少量方向一致的高光；维持克制水纹，避免仅增加更多白色直线。

验收方式：不依靠标题，可看出空间用途与动线；泳池有明确深度；相同植物不再形成等距复制带。

## 结论与关闭状态

第三轮仍未通过商业高品质成品或 AAA 视觉验收。没有因为轮次增加而降低门槛。雪山与别墅的原 P1 均未关闭；雪山的主景缺失、外围树木等距重复两个子问题获得明显改善，别墅的植物等距重复子问题有所改善。其他首轮 UI／人物近景／选角 P1 没有新对应证据，维持未复核。

### 雪山：实质改善，但 P1 未关闭

木屋提供了此前缺少的明确建筑焦点，暖色木墙与发亮窗户建立了雪景中的冷暖对照。外围树木已成组分布，并留有间隙，比前两轮单棵围绕更有疏密。新增近景提高了设施与人物占比。这些均是可以直接观察的修复，不应忽略。

仍存在的问题：木屋与主活动区之间的地面联系较弱；活动区新增蓝灰色道路呈明显规则格带，像覆盖在雪地上的半透明网格，不够像被踩实的雪路。近景人物仍偏小，能辨认服装轮廓但难读表情与视线关系。大面积地面和山体仍是接近单一明度的平滑白灰，材质、地形和接地层次不足。新增近景只能证明预览中有此镜头，不能证明实际经营模式默认镜头已经切换。

### 别墅：植物改善，水体出现可见退步，P1 未关闭

左侧盆栽已经打破整排等距铺满的模式，有两组集中分布，重复感有所减轻。近景使家具区域更容易观察，但也暴露地毯面积与家具占比失衡，且大片浅色表面之间缺乏材质差异。家具坐标属于玩家布置时，不应以重排玩家家具解决这一问题；应通过与设施绑定的局部装饰和地面细节提升组合完整性。

新增明显问题：art2 右下侧原有的青色泳池，在 art3-wide 相同区域变成大面积乳白平面；art3-near 也没有可辨识的水面。截图可以证实水体识别消失，不能凭截图确定是几何遮挡、材质或相机问题。必须查明原因，不能将消失的水体计为“泳池深度已修复”。原资产展示台感仍存在：大空地、均匀照明、弱材料分离和建筑层次不足。

## 最多三项最高价值修复

1. **优先恢复并核验别墅泳池的可见水体。** 对照 art2 与 art3 相同全景，检查水面、池底、池沿的高度和遮挡关系，再检查水材质透明度与颜色。验收要求：全景与近景均能辨认为水，能分辨池沿和水面，具有克制的深度渐变；不能只用一块纯青平面替代。不移动玩家设施。
2. **修正雪路与雪地的层次。** 保留现有设施与道路连接关系，将硬直网格状蓝灰带改为边缘不规则、渐隐的压实雪面；用连续但克制的脚印／磨损连接主活动区和木屋。增加局部冷色凹部及暖白受光，避免整片雪同一灰白。验收要求：原尺寸画面能读出行走路线，同时看不到人工网格贴片感。
3. **围绕保留坐标的设施做局部成套表达，并验证实际经营视角。** 别墅以设施包围盒为基础缩合地毯或添加绑定的小型软装／接地细节，区分布、木、玻璃的材料响应；雪山加强篝火／帐篷的局部暖色层次。镜头可适度收紧或在互动时进入人物近景，但须保持可操作区域可见。验收要求：提供真正的经营 UI 截图证明角色与关键操作可读，同时提供同机位全景证明没有为截图改变玩家布置。

本轮不要求再堆更多随机资产，也不建议为满足构图擅改玩家设施位置。三项修复完成后仍须基于新证据验收；它们不构成 AAA 达标承诺。

# 定向复核：唱歌识别与前景挡头

**本次静帧子问题由 P1 降为 P2。** 剪辑界面的素材图中，右侧黄色衣服角色头旁可见音符，姿态也与左侧自然站立的角色有区别；配合“开始哼唱旋律”的事件文字，动作含义比无符号的普通站姿明确。当前素材显示区域约为整屏四分之一宽，音符在实际 1280×720 截图里仍较小，因此单靠静帧图像而不读文字，识别把握有限。这个局限可记录为 P2，不再以“完全读不出唱歌”维持 P1；也不要求不断增加特效。

此图没有证明连续唱歌动作、口型、起止过渡或听者反应，动态表演验收仍未完成。静态提示有效与动态表演合格是两项不同结论。

## 前景挡住主角头部

**本次素材样例的具体缺陷关闭。** 源记录图中橙色衣服主角位于桌子左侧，头、面部和全身均可见；桌面、前景另一名角色的头部没有覆盖主角脸部。前景配角头部被画面下缘截断，但其没有遮挡事件主角，不以此替换原缺陷提出新阻断标准。

结论只覆盖提交的实拍样例。静帧不能证明所有布置、人物位置和全部候选机位都无障碍，但也没有理由据此拒绝承认当前样例已修好。若将来出现新遮挡应按新实例复现，而非把已修复样例永久保留为失败。
