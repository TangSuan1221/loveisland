# 荒岛心跳｜角色动作制作需求清单

## 一、制作口径
玩家是制作人，岛上嘉宾才是动作主体。主入口以 game.js 为准。购买设施、发指令、剪辑、播出、赔付是玩家操作；只有指令实际送达、嘉宾收到反馈或环境实际改变时，岛上才需要表演。选角、局外经纪、清算默认沿用界面；如要新增演出，再单独立项。

下文 P0 是建议先打通的录制闭环，P1 是正式玩法表现深化，R 是参考项目候选。编号代表可验收的动作需求或场景，不等于独立动画剪辑数。表内具体姿势、道具和优先级是制作建议。现状依据静态源码，未逐动作运行或认证美术质量。

**已见表现基础。** characters.js 按 gesture 驱动手臂、腿、头和身体，有 walk、talk、listen、share、argue、apologize、wave、read、rest、eat、dance、exercise 等分支；书、点心、音符、眨眼和说话嘴形已有基础。模拟层的默认活动点中 drink 指向 eat，sing 指向 dance，watch 指向 rest；显示层又按 eat/share 亮出点心。验收要走正式设施入口核对最终映射。尤其要分开“分享兴趣”和“递出实物”。

## 三、正式项目全部 24 个 NPC 互动模板
A、B 指当场角色。通用时间线为邀请、双方抵达、起话、回应、结果、散场。下表描述推荐表演，实际肯否与结算取模拟结果。需求触发依据本项目 NPC_EVENT_TEMPLATES。

|事件键|场景|触发依据|发起方|回应方及结果|
|---|---|---|---|---|
|chat|闲谈|社交需要|侧向招呼、开放手掌起话|转身、点头、轮换发言|
|share|分享兴趣|共同兴趣|兴奋比划共同兴趣|靠近看、补充或礼貌听；无实物不亮点心|
|play|一起活动|精力允许|发出舞步邀请、先走一拍|接受后错拍跟上，再同步收势|
|argue|意见分歧|直接程度有分歧|截住话头、挺直上身|摇头、守住站位或移开目光|
|apologize|关系修复|已有分歧|低头、摊手、等候|接受时肩膀放松，保留芥蒂时保持距离|
|alliance|结伴|熟悉且信任|指向共同目的地，再朝对方示意|认同时转到同一朝向，拒绝时留在原地|
|confess|表白|吸引且双方允许恋爱|对视、吸气、迈半步、等待|接受后主动缩短距离；婉拒时抬掌留距|
|question|询问旧事|前任关系或亲历分歧|试探性举手、观察对方|回忆后解释，回避时移开眼神|
|help|关怀|对方疲惫或饥饿|发现疲态、走到侧前方、示意休息|致谢或摆手示意能自行处理|
|boundary|表达边界|独处需求|后撤半步、掌心朝外|停步、放下手、让出空间|
|collaborate|共同创作|共同兴趣与创作目标|展现作品位置、示范一小段|看向共同焦点、接续示范或提出修改|
|complain|现场诉求|亲历服务失败|指失效设施、转向听者说明|循指看去、回应；不凭动作生成维修结果|
|resource-share|分享饮水|有空闲水位且对方渴|示意水位、让出使用面|接近并在有效服务点使用；避免双方同时占位|
|borrow|借物|有信任且对方持物|请求者伸空掌等待|持有人同意才交物，拒绝时收回|
|return-item|还物|本人持有借物|持有人展示借物并递出|物主伸手接稳后归位|
|comfort|安慰|看到对方难过或生气|降低姿态、保持可接受距离|抬头回应或转身独处；默认无需拥抱|
|clarify-belief|澄清误会|存在可追溯的主观判断|先疑问，再指向本人所知线索|解释、若有所思或仍保留判断|
|missed-promise|谈失约|存在逾期未履行约定|提醒约定、停顿等答|低头解释或坚持己见；不演成已履约|
|celebrate|庆祝进展|有未庆祝的目标进展|扬起手臂、看向同伴|拍手回应或微笑旁观|
|mediate|调停提议|亲眼见过当事人与第三人争执|面向当事人、掌心向下示意缓和|接受倾听或偏身拒绝；第三人可以不在场|
|queue-yield|让位|对方更急或优先|向队侧让一步、示意向前|点头后按实际队序前移|
|queue-argue|队列争执|双方坚持|指出队首或原站位|坚持原位、反向指认；争执不自动换位|
|queue-apology|道歉回队|后到者改变计划|后到者收手低头并撤回|先到者目送，对应队列恢复|
|queue-avoid|回避争执|先到者回避|先到者看向别处、转身离队|另一方保留实际位置，不追逐|

## 四、导演、摄影与人物差异
|指令|现场动作需求|失败、拒绝或延期|
|---|---|---|
|group 介绍／组局|接到邀请后找人，抵达再挥手，双方依次自我介绍|摇头或继续原活动；避免每次重演初识|
|interview 采访|先转向邀约方，接受后看采访位，回答间留出聆听节拍|拒绝只给避视或摆手；暂停排队期间零表演|
|mole 内应|接受后自然接近目标，借普通谈话提出指定问题|对方可以回避；远景别用夸张鬼祟姿势泄露身份|
|contest 挑战|双方就位、看开始信号、轮流打节拍、等待结果、回应|落拍和拒赛分开；未决前不演庆祝|
|feedback 反馈|收到信息的嘉宾可停顿、消化、向同伴回应|无人接收时不强制全员反应|
|weather 天气|天气变化后按个人暴露与当前活动缩肩、抬头或转移|独处、室内与已离场人物不统一同步表演|

**可复用表现层。** 建议把下列需求作为混合参数或短叠加动作交付。性格改变动作幅度、停顿和先发意愿。关系决定朝向与距离；可接触范围由当场回应决定。

|维度|可见差异|验收对照|
|---|---|---|
|社交主动／保留|先挥手、大幅展臂／等对方看过来、小幅点头|同一句问候，远景能辨主动方|
|直接／委婉|立即转身摊手／先移开目光再开口|两者都能表达明确拒绝|
|精力与个人习惯|轻快步、随口哼唱、好奇探头、步行微摆|持杯、读书时让出已占用手臂|
|平常／开心／心不在焉|稳定呼吸／抬头舒肩／视线游移、慢半拍回神|切换心情不重启整段行走|
|担心／烦躁／生气|搜寻目光／反复挪脚／身体立直、手势变硬|区分忧虑、等待不耐、针对人的愤怒|
|沮丧／消沉／绝望／濒饿|短暂垂头／持续收肩／失去回应后缓缓坐低／护腹步弱|分别核对触发，不把所有负面情绪演成闭眼|
|心动／尴尬／嫉妒／释然（建议演出）|回看／短暂避视／视线在两人间切换／缓缓呼气放肩|单向心动只出现在该角色身上|
|说话与倾听|发言者有口型及重音手势；听者闭口、看向当前说话者|插话、沉默、旁听三种时机可分|
|编辑器与选角|中立站姿、自然眨眼、稳定头像朝向；侧背检查时减少摆动|眼镜、发型、彩绘脸及隐藏基础五官配置均可预览|

## 六、资产拆分、接入与验收
1. **基础交付**：站、走、转、停、坐、起、取、持、递、接、收、推拒、退步各有独立进出姿势。对话用“发言起手—可循环主体—收手”拼接；强分支如表白拒绝、水站让位单独做回应与散场。估工时以母动作、道具适配、双人编排、引擎接入和验收分别计数。
2. **挂点和设施**：定义左右手、口部、视线、脚底、座位、出水口、取餐面、物品交接点。建议先交杯、食物、书、可借物四种道具。递物要有双方共享的接触帧；所有权、库存和服务扣减以模拟提交点为准，视觉层不重复写入。
3. **人物适配**：覆盖最矮／最高、宽／窄身形、长发、眼镜、不同衣装及自绘脸。手到嘴、杯沿、书页、握手距离需要逐类校正；没有手指、肘膝或面部控制能力的模型先验证整臂、头部和道具构图，精细接触另估。
4. **镜头验收**：同一场分别录上帝视角全景、事件双人镜头、单人反应近景和结果静帧。关闭气泡、姓名和音效，请观察者指出发起人、对象、接受／拒绝和队列变化。倾听者不做成同时说话；静帧优先保留能解释前因与反应的构图。
5. **时间与抢占**：实测 1×、2×、4×、暂停／恢复、跨时段、收工截断。暂停不偷偷推进接触点；中断时按提交点前后恢复道具、占位、目光、口型与手臂；禁止收工后补生成关系结果或采访素材。
6. **异常路径**：座位满、设施被移动／拆除、无水、暖炉断电、目标离岛、双人路径不可达、第三人路过、续谈失败均要走退出动作。高低体型互换 A/B；同一人物先借再还，重复暂停；检查无悬浮道具、瞬移、穿人和队序倒置。
7. **首批验收场**：一位嘉宾前往水站，另一人请求优先；分别跑让位、争执、回队、回避四个结局。接着在独立存档跑一次表白被拒、一次借还、一次中断续谈。前者验证走停、设施、队形与双人节拍，后者验证边界、物权和跨场连续性。
8. **排期顺序**：先做水站和基础双人对话，再补恋爱回应、导演采访和道具交接；之后做个性叠加、气候、替补离场及镜头近景。参考扩展按已获批玩法选整条链制作，例如接雨—搬水—分水—争配额，不单独采购脱离机制的片段。
