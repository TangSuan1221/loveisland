# 收视率暴君：荒岛恋综制作人

英文工作名：Ratings Tyrant。类型：单人模拟经营、轻量沙盒建造、角色关系模拟、叙事剪辑。文档版本：1.0，2026年11月12日。

玩家经营一家濒临出局的综艺制作公司，在封闭海岛上安排嘉宾、空间和节目规则，把真实发生的互动剪成能卖出去的故事。核心挑战是：今天最有效的收视手段，可能毁掉明天愿意合作的嘉宾、观众信任和公司现金流。

本文规定系统职责、状态流转、收益与代价、首个可玩版本和验收条件。所有数值均为原型初值，供实现与测试，不代表已经验证的平衡结果。

## 一 产品定位与设计支柱

### 1.1 核心承诺

一句话简介：通过选角、布局、暗箱操作与恶魔剪辑，把不可完全控制的真人秀变成传媒生意，同时承担自己制造的后果。

玩家的主要乐趣来自三个连续动作：预判一组人物会发生什么；观察他们以意外但可解释的方式行动；决定如何向观众讲述这些事情。黑色幽默来自制作流程、指标和真实情感之间的矛盾。

本作不承诺无限自主的通用AI。人物由可解释规则驱动，故事通过人物目标、关系变化、设施条件与有限事件组合涌现。原型采用固定镜头、事件卡和短对白，不制作逐帧可剪的真实视频。

### 1.2 四项设计支柱

| 支柱 | 应产生的玩家决策 | 明确边界 |
|---|---|---|
| 布局改变关系机会 | 把谁安排在共享资源、路径和活动附近 | 建筑不直接指定谁爱谁或谁背叛谁 |
| 人物有自己的利益 | 利用已知关系，同时承担隐藏动机的不确定性 | 玩家不能直接操纵所有嘉宾 |
| 同一事实可有不同节目版本 | 选择主线、顺序、旁白和被省略的语境 | 剪辑不能回写岛上历史 |
| 成功会留下债务 | 在短期热度、收入与长期合作之间取舍 | 冲突强度不等于净利润 |

### 1.3 基础体验参数

以PC单人离线体验设计，支持暂停及加速。标准季暂定6名嘉宾、7个录制日、7集节目，目标单季体验90至150分钟；垂直切片缩短为4名嘉宾、3日、3集。一天录制对应当晚一集播出，采用游戏化压缩制作流程。

局内没有强制淘汰投票，以免过早破坏关系网络。嘉宾可退出、被暂停录制或在季末离岛。常规角色均为成年人；恋爱偏好是普通匹配条件，不能作为心理缺陷或固定负面标签。身体接触由角色接受度决定；拥挤空间催生的是边界协商与资源矛盾，不自动触发亲密行为。私人洗浴区不可摄录；原案的单面镜淋浴改为公共采访间与透明规则的私密空间分配，保留偷窥式制作人的讽刺，但不依赖性侵犯画面提供收益。

## 二 时间结构与完整循环

### 2.1 三层循环

| 层级 | 输入与操作 | 输出 | 对下一轮的影响 |
|---|---|---|---|
| 录制时段 | 需求、设施、关系；布局与有限导演指令 | 事实事件、人物变化、可用素材、干预证据 | 新关系改变后续互动；事故降低可录制能力 |
| 每日节目 | 当日及历史素材；组装叙事段落并锁片 | 观众反应、现金结算、公众印象、争议 | 次日节目目标、赞助条件与嘉宾合作变化 |
| 每季经营 | 公司现金、历史人物、已解锁能力 | 季评级、签约机会、研究进度、竞争变化 | 决定下季阵容、预算、地图和市场位置 |

### 2.2 每日状态机

晨间到期事项检查 → 布局维护与排程 → 上午录制 → 午间检查 → 下午录制 → 晚间录制 → 剪辑 → 锁片与播出 → 财务与争议结算 → 下一日。晨间只检查和处理未付到期事项，晚间汇总账本，不重复结算。

经营日期是合同、案件与贷款的共同时间基准。完成正常日、维护日或选择“等待一天”均推进一天，停留界面思考不消耗时间，也不产生收入或恢复效果。停录及维护日占用原定季日程，达到季末日期即收季，不自动补足录制日；下一季筹备完成需消耗一个经营日，开季前先处理到期义务。

录制支持暂停和1/2/4倍速，剪辑不计现实时间。各录制段结束后保存检查点。设施移动与拆建只允许晨间和午间施工窗口，支付施工费并暂停相关设施；不能在争吵发生瞬间移动帐篷改变结果。玩家可以不使用指令，每晚必须选择正常节目、补救节目或停更之一。前两者进入锁片与播出，停更直接进入当日财务与争议结算；所有分支推进日期及案件截止日。

播出后，外界信息默认不直接进入嘉宾认知。离岛嘉宾可立即看到节目；留岛嘉宾只会通过公开反馈会、访谈或泄露事件获知片段，且这些渠道会生成认知记录。这样保留“公众以为”和“人物知道”之间的差异。

### 2.3 首日教学

预置可运行营地 → 选择一组已知矛盾的嘉宾 → 移动公共餐桌改变相遇 → 观察一个有清晰动机的互动 → 用同一组素材做两个节目预览 → 锁片并查看收入、误读与合作变化。

教学必须让玩家看到至少一条“我的操作—人物行为—素材—节目效果”的因果链。教学不把羞辱、剥夺补给作为唯一获胜办法。

## 三 系统拆分与数据权责

### 3.1 子系统职责

| 子系统 | 负责写入 | 读取 | 不负责 |
|---|---|---|---|
| 选角与合约 | 阵容、费用、公开信息、预置关系 | 人物库、公司信誉、历史 | 直接创造每日剧情 |
| 岛屿与设施 | 可达性、容量、舒适、隐私、摄录覆盖 | 地图、设施配置、天气 | 修改爱慕或信任 |
| 人物模拟 | 行动、需求、私人关系、记忆 | 目标、认知、空间与资源 | 观众评分、收入与合作意愿W |
| 事件裁定 | 唯一事实事件、参与者与结果 | 行动请求、前置条件 | 为KPI强行保证结局 |
| 摄录与素材 | 可剪素材、拍摄缺口、语境关联 | 已发生事件、机位与人员 | 生成未发生的事实 |
| 导演干预 | 指令、环境请求、证据痕迹 | 行动额度、现金、现场条件 | 绕过人物拒绝与安全状态 |
| 剪辑叙事 | 节目时间线、命题、语境偏差 | 素材及版权式使用标记 | 更改事实记录 |
| 观众市场 | 分群评分、有效收视、公众印象 | 成片、历史疲劳、信任 | 直接改变人物私人关系 |
| 风险与合作 | 争议案件、处罚、合作意愿W、合同状态 | 证据、负面影响、合约 | 重复扣除同一案件罚金 |
| 财务与局外 | 账本、公司资产、成长与竞争 | 收入、成本、已结算事件 | 反向生成素材 |

### 3.2 核心数据对象

- 人物：身份、公开履历、隐藏目标、行为特质、恋爱偏好、需求、合作意愿、个人记忆、已知事实。
- 有向关系：A对B的信任、吸引、怨怼，及关系事件索引。A喜欢B不意味着B喜欢A。
- 事实事件：事件ID、日期时段、参与者、地点、原因、可观察行为、实际结果、知情者与证据。创建后不可修改，只能追加澄清事件。
- 素材：素材ID、源事件ID、镜头主体、覆盖完整度、可理解性、情绪强度、语境片段、可用旁白模板、已播次数。
- 节目段落：主角、叙事命题、选用素材与顺序、字幕/BGM、缺失语境、预计受众与风险区间。
- 争议案件：关联命题、证据来源、受损人物、严重度、处理截止日、状态、唯一结算ID。
- 经济流水：交易ID、来源阶段、金额、现金前后值；同一播出或案件禁止重复入账。

### 3.3 更新顺序与确定性

每个模拟步按“环境与需求更新—健康检查—现有行动推进与中断—已完成行动及事件裁定—关系与记忆更新—摄录归档—空闲角色选择新行动并申请预约”执行。动作状态为待选、申请、移动、排队、执行、完成或中断。行动具有持续时间；角色和设施槽位同时预约成功才能开始，多人行动采用全成功或全释放，不能部分占用后互相等待。每名角色最多执行一个主行动，旁观只生成认知，不占用第二个主行动。多个角色竞争同一容量时，采用已预约优先、等待时长次之、固定种子随机打破平局。

救援优先于退出、设施失效和普通活动。中断释放角色及设施预约，已发生的行为保留为事实，但尚未完成的奖励和关系结果不结算。路径失效立即重新规划；无合法路径则应急撤离，暂停受影响录制。等待超过一个录制段或对象退出则取消行动，不能无限占位。每段结束时普通活动全部完成或取消，睡眠、治疗通过独立恢复计时器延续，不保留失效主行动预约。资源申请时仅锁定库存量，完成交付时才扣实际库存，中断退回未交付锁量。摄录采样可记录进行中的行为，只有完成或中断时才封装素材并引用对应结果。

角色状态机唯一写入录制资格，包含可录制、任务拒绝、退出协商、医务、已离岛。风险与合作模块独占更新W，人物模拟只读W并提交拒绝意图；救援及风险模块提交状态转换请求，由状态机裁定并产生唯一事件。医务和已离岛不计可录制人数；任务拒绝与退出协商仅能自愿生活录制，不计常规拍摄阵容。医务恢复须H低于30、危险来源消除且完成至少一个录制段的治疗；当日因H达到80退场者最早次晨恢复。

同一存档、种子和指令序列产生相同结果。事实、摄录和市场分别使用随机流，避免在剪辑界面调整音乐改变未来天气。读档允许试验，但不是经济平衡所依赖的惩罚机制。

## 四 选角与人物模拟

### 4.1 选角不是标签配方

每名嘉宾包含公开人设、长期目标、当前诉求、行为倾向和可发现秘密。示例：公开热心的求职者实际想争取品牌代言；看似冷漠的嘉宾优先保护隐私。隐藏信息通过试镜、访谈、相处和事件揭示，调查需支付费用或占用筹备槽位。

选角界面展示预算、角色目标覆盖和已知关系图，提示“可能争夺领导权”，而非保证“必然爆发争吵”。秘密有确定数据，不在玩家选择之后临时生成来惩罚正确决策。已有前任关系来自人物库，不允许随意给任意两人补写历史。

### 4.2 状态与行动

需求采用0至100的缺口值，越高越需要满足：饥饿、口渴、疲劳、环境不适、隐私不足。综合压力P为需求缺口加权和，温暖地图暂定权重0.25/0.20/0.25/0.15/0.15。每个模拟步按经过时间累积缺口，吃饭、饮水、睡眠、遮蔽与独处分别减少对应缺口；服务只有完成后扣库存并恢复状态。合作意愿W、目标进展和人物关系独立计算，不能压缩成一条压力条。

身体危险H为独立的0至100状态，不由P直接替代。口渴或环境不适达到90并持续一个游戏小时，或发生事故时，H按事件配置增加；脱离危险并接受治疗后下降。H达到60立即停下角色行动并送往医务点，达到80则当日退出录制。若医务通道失效，触发不依赖导航的场外救援并暂停全场。救援支出记入现金处理流程，不能因为支付失败拒绝救援。健康事件不额外奖励情绪强度，避免刷救援获取高分。

P低于35为稳定，35至69为紧张，70及以上为高压。压力提高短期自保权重，降低复杂社交耐心；不同特质会表现为争辩、回避、求助、照顾别人或拒绝拍摄。高压不自动意味着自私或暴力。

每次决策生成合法候选行动：吃饭、休息、取水、参与活动、结盟、表白、质问、独处、投诉等。效用评分为需求缓解＋目标推进＋关系偏好＋性格匹配－体力成本－预期风险。只在分数接近的候选中随机选择。重大行动具有条件：表白需有吸引基础，公开指控需有主观证据，罢录需低合作意愿或重大边界事件。

### 4.3 关系与记忆

信任、吸引、怨怼分别取0至100。事件按角色解读增减，单个普通事件变化上限暂定10；重大背叛可突破但必须有预设规则和提示。短期情绪随时段衰减，关键记忆长期保留。人物只根据自己知道的事件行动，误会必须有来源，揭示真相才可能改变误会。

共同完成任务可能提升信任但不提升吸引；拒绝约会可能降低吸引却提升边界信任。恋爱线、竞争线、友谊线都可提供高价值节目，避免所有人物围绕同一恋爱公式运行。

### 4.4 拒绝与退出

合作意愿低于30时出现拒绝部分任务；低于15且经过一次沟通仍未恢复，或发生重大边界事件，进入退出协商。玩家可以道歉、改善条件、调整任务或接受离岛；付款不能保证恢复信任。退出前保留一个可响应窗口，紧急救援除外。

当日开录前可录制嘉宾少于3名则不能继续常规录制，转入补救节目或提前收季。录制中可录制人数降至2名时立即结束该日常规录制，已有素材仍可剪辑，自愿生活摄录不受该门槛限制。完整版本允许预先签约的替补在次日入场；切片无替补。

## 五 岛屿建造与资源系统

### 5.1 五类设施

| 类别 | 基础功能 | 戏剧变量 | 代价与反制 |
|---|---|---|---|
| 生存设施 | 水、食物、睡眠、遮蔽 | 容量、排队、分配权 | 高压降低工作与录制能力；紧急保障自动介入 |
| 社交设施 | 餐桌、篝火、双人任务台 | 接触人数、活动门槛、公开程度 | 重复同类活动降低新鲜度 |
| 差异设施 | 舒适小屋、普通营地 | 奖励资格与资源差异 | 透明竞赛可被接受；任意偏袒损害合作 |
| 制作设施 | 固定机位、采访间、导播站 | 覆盖范围、语境完整度 | 占地、购置与维护成本 |
| 恢复设施 | 独处区、医务站、沟通室 | 休息、倾诉、关系修复 | 占用时间与机位机会，但保护后续素材 |

### 5.2 布局变量

设施拥有格位、入口、容量、服务时长、有效范围、噪音、舒适、隐私和每日维护费。路径与距离改变行动成本；共享设施提高相遇机会；机位只捕获覆盖范围内的外显行为，不能拍到角色内心。

水井靠近某人的住处会增加打扰和相遇，但不自动赋予水井所有权。要制造分配冲突，必须额外设置“值日管理权”等节目规则，并让嘉宾知道规则。高级住宿通过公开任务授予，可形成策略与联盟；随意撤回奖励会累积失信记忆。

### 5.3 补给与建造约束

食物、水、电力是岛内消耗量，由设施和每日采购提供，不成为跨季货币。库存不足会触发采购提示与备用保障；保障成本高并暂停受影响录制，禁止通过将人物长期困死来无限刷高压素材。地图验证必须保证营地、应急点和基本补给可达，封死所有道路的方案不能确认。

购买设施扣现金；日常运行继续扣维护费。拆除退回原价的40%，设施移位收取原价的10%，同一设施当日仅可移位一次；原型可调整比例，但不可无损回收。施工禁止封堵在用设施出口。租用海岛的局内设施季末不自动转为公司资产，未拆除设施按购置价40%乘剩余完好度回收；已拆除设施不再次回收。公司永久升级另行记录，固定保障点不可出售。

## 六 导演干预与事件系统

### 6.1 干预预算

每日提供3点导演行动额度，不可存到下一日，且所有干预另有现金或合作成本。每个录制段最多执行一次同类干预；大型天气/资源事件每日最多一次。额度不是通用货币，不能直接购买永久解锁。

| 操作 | 前提 | 消耗 | 可能收益 | 风险 |
|---|---|---|---|---|
| 调整分组 | 活动开始前、角色可参与 | 1额度 | 提高特定人物相遇概率 | 重复针对会被察觉 |
| 给内应耳返 | 已签内应、非忙碌、目标合法 | 1额度＋约定费用 | 引导话题或行动 | 可拒绝；留下指令证据 |
| 公开反馈卡 | 已有真实播出反馈 | 1额度 | 引发自我修正或关系冲突 | 改变嘉宾对节目组的认知 |
| 资源竞赛 | 有合法奖品和规则 | 2额度＋物资 | 制造选择、结盟和反转 | 不公平规则降低合作 |
| 人工天气 | 地图有设备、保障达标 | 3额度＋设备费 | 改变共同任务条件 | 停机、修复费、干预证据 |

人工天气属于后续内容，切片只有自然天气和分组/内应两类干预。内应不是必定成功的按钮，其目标、拒绝条件与暴露风险和其他人物一致。指令失败不返还已占用额度，未发生的奖品交付不扣物资。

### 6.2 事件模板与冷却

每个事件模板定义前置条件、行动发起人、参与者响应、资源预约、结果分支、关系变化、可拍摄节点、冷却与证据。系统优先裁定角色主动行为，再考虑自然环境与节目活动。编剧型事件只能提出机会，不能替人物选择结果。

同一人物组合、同一触发原因的冲突在同一日内具有递减价值；重大剧情需要不同条件或关系状态变化才能再次发生。沉默、和解、合作成功也可形成节目节点。当天缺乏戏剧事件时允许用实际取得的采访、回顾和生活片段制作补救节目；仍无足够素材则停更。

### 6.3 事件配置示例

“水站排队争议”触发条件：水站可达且正在服务，A与B均口渴超过50，A已经排队，B具有插队动机且选择尝试插队。系统预约两人及水站交互槽，持续10个游戏分钟；每对人物每日最多一次。排队属于可打断行动；事件开始时原子地将A、B的主行动预约转交给事件，保留队列位置作为恢复信息。事件结束后按分支恢复或改变队列。交互槽与饮水服务槽分离，不取消正在服务的第三人的预约。

| 分支 | 人物响应条件 | 世界结果 | 可录素材 |
|---|---|---|---|
| 让位 | A更重视关系或B说明急需 | B先饮水；A对B信任可能上升 | 请求、让位、感谢 |
| 争执 | A选择质问、B坚持 | 队列暂缓；双方怨怼增加，结果仍需协商 | 插队、质问、回应、解决 |
| 道歉 | A质问后B改变计划 | B回队尾；怨怼小幅恢复 | 冲突与修复均可使用 |
| 回避 | A不愿公开冲突 | A离开另找水源或投诉 | 离开镜头不能自动证明受欺负 |

分支由效用选择确定，不根据导演当日KPI选取。未被摄录的插队起因保留在事实库，但不能自动生成镜头。事件造成的饮水效果只在实际服务完成时生效，不额外发放一份水。假设角色中途进入医务，事件中断，既有片段保留，未完成道歉不结算信任奖励。

## 七 摄录与恶魔剪辑

### 7.1 从事实到素材

事件发生不等于获得完整素材。摄录覆盖决定是否获得起因、行动、反应、结果四类片段。原型每个事件生成1至4张可视素材卡，包含短动画或定帧、字幕和标签。玩家可查看自己录到的完整上下文；未摄录事实只通过现场报告提供不完整信息，不能成为可播证据。

原始素材按日归档，跨日可调用但必须承担时间错配风险。回顾镜头有明确标记；同一素材再次作为新证据使用会降低新鲜度并提升被识别概率。原始记录不能删除来消除已存在的证据风险。

### 7.2 成片结构与操作粒度

正常节目固定3个段落槽，每段2至4张素材卡，依次承担同一主线的铺垫、发展、结果/悬念。玩家先选择主线命题，如“A与B关系升温”“A被B拒绝”“A独占资源”，各段继承同一组核心人物与主题，并选择支持或反驳该命题的素材。模板读取参与者和证据标签；不允许自由输入任意指控，由有限语义系统确保可判定。第一版不加入独立副线，以免三个不相关片段也被当成完整故事。

补救节目只需1个段落、2张有效素材卡，质量和赞助资格受限，界面明确标为缩短版，不能按正常节目领取完整交付奖金。若连补救节目也无法组成，允许停更。采访需要嘉宾配合，生活片段需要有效摄录，不凭空发放兜底素材。自动组片只使用现有合法素材，提供最少操作的低偏差草稿；无合法组合时提示停更。

操作包括选择片段、调整顺序、省略语境、添加字幕模板、选择音乐情绪与标记回顾。音乐改变感受强度，不能单独把没有拒绝行为的素材变成真实拒绝。镜头不足时可插入采访或低收益生活片段；关键命题缺乏支撑时仍可播为误导剪辑，但明确显示风险。

同一事实的三种组装：

1. A被烟熏流泪＋B递水：合作与关怀，低偏差，适合关系观众。
2. B路过＋A流泪＋“他没有停留”字幕：暗示冷漠，缺失因果，短期争议更高。
3. A说“不是因为他”＋流泪＋完整采访：澄清前集，减少偏差，但可能让冲突观众失望。

### 7.3 内容评价

每段产生可理解性C、情绪强度E、人物连续性A、新鲜度N和语境偏差D，均为0至1。基础质量Q=0.30C＋0.25E＋0.25A＋0.20N。重复使用同一人物、同一矛盾或同一素材都会降低N；高情绪但无起因与结果的混剪会损失C与A。

D来自四类可查问题：跨事件拼接导致错误因果、颠倒先后、删去反证、字幕命题与证据冲突。系统不以“用了悲伤音乐”自动判假。偏差只提高部分观众的即时注意力，同时积累可追溯的真实性债务。同源事件的多机位、复制和裁切不重复贡献新鲜度，同一素材在同集只能首次使用时贡献质量价值。

悬念结尾创建一条观众承诺，记录主线、待回答问题和截止集，默认须在后两集内兑现。后续结果可以是失败、拒绝或关系中止，不要求圆满；必须提供新的结果证据。重复吊同一悬念不重复增加注意力，逾期降低该群体下一集留存，最多计算一次逾期惩罚。嘉宾离岛可用已有离岛素材与回顾收束；季末仍无有效结果证据或提前停播时，承诺自动标记未兑现，结算一次留存或季评价损失后关闭，不阻止收季，也不凭空生成结果素材。已计过逾期惩罚的不重复扣同类损失。

真实性债务是未纠正误导命题的严重度总和，不直接扣现金。只有案件进入成立状态才产生赔付、撤资或整改成本，避免债务条和案件重复罚款。赔付结清案件责任，不抹除错误叙事；公开提供有效澄清后，命题标为已纠正并移出债务，已发生信任损失不会立即恢复。案件驳回不自动证明原命题正确。剪辑预览显示受众预测、偏差原因和风险区间，不公布尚未知晓的爆料时点。

### 7.4 锁片与风险响应

锁片前可无限修改和比较；播出后成片不可撤回改写历史。更正以新节目段落或公开说明追加，会占用内容槽/费用。有足够合法素材时提供低偏差组片路径；无足够素材时允许补救或停更，不设置必须造谣才能完成的主线KPI。

节目目标是可选商业委托，例如提高特定嘉宾曝光或延续一条关系线；未完成只损失约定奖励，不阻断日循环。监管目标则是硬约束，违反可能进入停播流程，两者在界面分开。

## 八 观众 收入与风险闭环

### 8.1 观众分群

基础观众分为关系观众、冲突观众和观察观众，分别偏爱人物积累、强烈对立和行为真实性。每群拥有规模、满意度、疲劳和信任。热搜代表注意力，收视代表有效观看，信任影响留存，三者不能互换。

有效收视采用归一化指数V，不作为可花费货币。原型每群贡献为“可触达规模×吸引度×留存系数”，再求和。吸引度由质量、类型匹配和有限话题加成决定；话题加成上限为基础吸引度的25%。留存系数受满意度、连续性、疲劳与信任影响，范围0.2至1.0；具体曲线通过测试拟合。

观众只根据播出的节目与公开证据更新判断，不直接读取隐藏真相。内部偏差D预测潜在风险；只有矛盾镜头、爆料或更正公开后才降低相应群体信任。观众可喜欢恶意节目，但重复套路、嘉宾退场和失去故事结局仍会损害留存。

### 8.2 经济账本

现金是唯一通用支付资源。公司信誉影响合同与招募；制作经验解锁工具资格，两者不可直接兑换现金。岛内库存、导演额度、观众指标分别属于运行资源、行动约束与结果，不混成“点数”。

现金余额＝上日余额＋当日全部已支付流水之和。各现金动作发生时立即写入唯一交易；日结只汇总和处理尚未付款的应付项。流入包括广告、已达成赞助款、资产回收、商务结算和借款；流出包括开季合约、日常运行、设施维护、购置/移位/维修、采购、调查、干预、赔付、借款本息和永久升级。日常运行费包含团队日薪、基础保障与场地日租；嘉宾出场费、设备费和赞助尾款按合同分别定义付款时点，不能同时计入多个科目。借款是融资现金流，不计经营利润。

广告收入＝广告单价×有效收视指数。单价由已签合同固定，下一季才会因市场与信誉重新议价。赞助每季有支付上限，不能重复触发同一任务。补救节目广告收入按正常公式的40%支付，不领取正常交付赞助；停更广告与交付赞助均为零。开季界面显示已签固定收入、预计收入区间、全部必要支出和零广告情况下的可支撑天数，不把未达条件赞助当作保底现金。

初始可试算案例，单位为游戏币：开季现金100,000；选角12,000、基础设施20,000、筹备8,000后剩60,000。每天运行及维护费合计6,000，干预预算平均2,000；广告单价100，V=90时广告收入9,000，满足赞助条件得到2,000，当日净增3,000。若一次高风险节目令V升到110但产生8,000赔付，当日收入13,000、支出16,000，净减3,000。假定当天无其他资本支出或融资；此例只展示账本关系，不代表高风险每次必然赔付。

### 8.3 争议案件

潜在命题 → 证据出现 → 投诉/爆料 → 调查窗口 → 成立或驳回 → 赔付/整改/更正 → 结案。案件只在一条轨道中结算一次。真实负面行为也可能引发嘉宾不满，但只有节目误导、违约或实际干预证据才支持对应责任，避免所有高热度自动遭惩罚。

原型由确定性证据阈值加固定种子延迟决定爆料，不使用无提示的纯随机封杀。每次重大处理至少提前一个结算窗口预警；重大现场事故可立即停录。玩家可以提供上下文、发布更正、协商赔付或坚持播出。处理方式影响现金、信任和合作；付费压制不是通用消案按钮。

监管采用完全虚构的行业审查机构。一般问题警告，重复严重问题进入整改，未满足整改条件则停录或停播。停录日可维修、采购、处理案件，使用已有素材制作补救节目；停播日禁止发布任何节目，只能维护与整改。界面提供“结束维护日”，照常推进经营日期并结算基础开支、到期案件与合同责任，满足恢复条件后次晨复工。严重或重复重大违约会提前结束本季；具体处罚类型由案件规则明确，不随机改变。

### 8.4 失败与恢复

| 失败类型 | 触发 | 当下损失 | 恢复途径 |
|---|---|---|---|
| 素材不足 | 可用片段无法组成正常节目 | 降低质量与赞助完成度 | 采访/生活片段或停更，停更无广告收入 |
| 嘉宾退出 | 合作或边界触发 | 损失关系线与可录制人数 | 调整节目、预签替补、提前收季 |
| 临时停录 | 补给、设施或整改不达标 | 时间、维护费与排期 | 自动保障、维修与达成整改 |
| 现金危机 | 可用现金不足以支付下一笔必要费用 | 强制进入经营处理界面 | 出售可售资产、一次过桥贷款或提前收季 |
| 公司破产 | 已到期必要义务无法履行且无可行清算/融资方案 | 结束该经营档 | 保留内容图鉴，开启新档；不保留经济优势 |

现金不足时先冻结可选支出，再计算可售资产、允许融资与提前收季后的清算结果。必要义务包括工资、基础保障、救援、到期合同与赔付；提前收季仍不能覆盖到期义务时进入破产，不能无限停在处理界面继续生产收益。救援优先执行，不足部分形成应付款。

过桥贷款每季最多一次，额度不超过可清算资产价值的50%，利率暂定10%，下一季筹备前还本付息。存在未偿本金时禁止新借，前一笔清偿且进入下一季后才恢复申请资格。季末允许提前还款；借款不计开季最低自有资金。未付案件和合同使用原经营日期跨季保留，不重置截止日；季末先结清已到期责任。开季最低自有资金暂定为开季必付项加两日必要运行费，扩张不达标时必须降低规模；若最低可选规模仍无法满足门槛，提供主动清算并结束经营档的出口，不允许无成本等待产生收益。

## 九 局外成长与终局

### 9.1 季末结算与MCN

季末先结清尚未支付的合同尾款、设施残值、赞助尾款和到期案件，不重复支付每日已付工资；再评估季表现，最后开放签约与升级。热度不等于嘉宾愿意签约；签约取决于公众价值、私人信任、替代机会及报价。签约支付一次性费用和持续保底，占用有限管理席位。

签约嘉宾每季只能选择一项主业：参加本公司节目、商业活动或休养。商业活动收入由公众价值和匹配度决定，扣除保底与分成，并受曝光疲劳与争议影响。派去录节目就放弃同期商务收益，避免签约成为无限被动印钞。离岛人物记住历史事件，回归需要满足合同与个人目标，不能无成本重置为“复仇工具”。

### 9.2 科技与地图

成长解锁新决策维度：更多机位提升语境覆盖；访谈工具揭示动机；规则设施允许新型竞赛；高级剪辑模板增加叙事选择。升级必须同时支付现金并达到制作经验门槛，制作经验仅由首次里程碑和季末评价提供，重复播出不能刷取。

| 地图 | 特有变量 | 保留的通用接口 | 引入条件 |
|---|---|---|---|
| 热带海岛 | 补给、降雨、公共空间 | 需求—设施—行动—事件—素材 | 基础版本 |
| 雪山木屋 | 温暖容量、室内拥挤 | 环境不适仍写入同一需求字段 | 海岛循环验证后制作 |
| 楚门别墅 | 公开/私人信息边界、设备维护 | 隐私需求、认知渠道、证据案件 | 后续扩展；不另造万能控制系统 |

### 9.3 竞争与收购

竞争台以简化经营模型运行：每季有定位、预算和节目品质，竞争有限观众池，不能让所有台同时获得全额市场。竞争不是实时模拟另一座岛。原型不制作此系统，只保留季末市场报告接口。

完整版本的收购条件为：达到目标估值所需现金、满足连续盈利门槛、保持最低公司信誉、没有未执行的停播决定。目标估值随其资产与观众份额变化；收购后新增运营费与整合任务，而非现金瞬间回流。市场胜利定义为收购老东家与指定竞争集团，完成最后一个盈利季；“垄断”作为虚构结局叙事，不声称模拟现实并购规则。胜利后可进入自由经营。

## 十 界面与玩家反馈

主界面展示现金及下日预计支出、在场人数、补给余量、导演额度和风险预警。人物卡将“玩家已知”“角色已知”“公众印象”分栏，防止信息混淆。关系图支持筛选信任、吸引、怨怼，避免用一条好感度混合解释。

事件日志提供“为什么发生”：角色当下目标、主要需求、触发设施与已知事件。不会直接泄露未调查的秘密，只显示可观察理由。素材卡可跳转源事件，成片可查看每个命题的支持片段与缺失语境。

播出报表把预计和实际分开，说明差异来自受众匹配、疲劳、公开证据还是赞助未达标。弹幕与热搜承担情绪表达，详细报表承担规则解释，不让玩家靠大量文字猜惩罚原因。

## 十一 内容生产与技术边界

### 11.1 内容单位

人物模板由目标、特质、行为限制、短对白池和秘密构成；事件模板由触发与结果构成；剪辑模板由命题与证据要求构成。三者独立配置，通过参与者和事件标签关联。对白服务于已经裁定的行为，不让生成文字自行修改游戏状态。

首版不依赖在线大语言模型。后续若加入生成对白，只作为表现层，必须回落到模板；事实、数值、认知与存档由本地规则决定。所有节目镜头使用角色和场景资产复用，不承诺电影级多机位视频剪辑。

### 11.2 存档与调试

存档包括随机种子及各随机流位置、人物状态、关系和认知、设施预约、不可变事件、素材使用记录、成片、案件与账本。存档版本变化必须迁移或明确拒绝加载，不能静默丢弃债务。调试面板支持按事件ID还原因果链，并比较同一种子的不同决策路径。

## 十二 开发拆分与验证门槛

### 12.1 分阶段范围

| 阶段 | 交付范围 | 明确不做 | 进入下一阶段条件 |
|---|---|---|---|
| P0 规则原型 | 2名人物、需求与关系、3类设施、事件日志、素材卡 | 美术成片、完整经济、局外 | 布局和目标能稳定产生可解释的不同结果 |
| P1 垂直切片 | 6名候选中选4名、3日、8类设施、12个事件模板、6个命题模板、3类观众、简化案件与完整账本 | MCN、科技树、竞争台、人工天气、替补、贷款、多季续局 | 从选角到季末全流程无死路，核心策略可比较 |
| P2 最小完整产品 | 6名在场/12名候选、7日、海岛、约24个事件模板、成长与有限MCN | 雪山、别墅、全面并购 | 多季仍有不同策略且经济不失控 |
| P3 扩展版本 | 新地图、竞争与收购、更多人物事件 | 无条件承诺全部实现 | 核心留存及内容成本达标后决定 |

P1的8类设施为水站、餐台、普通帐篷、舒适小屋、篝火、采访间、机位、独处区；医务与应急补给为固定保障点。P1现金危机使用资产出售、提前收季与破产处理；季末保存未结案件快照，不宣称支持真实跨季。贷款和跨季责任验收属于P2，P1只检查其数据可序列化。P0仅用于局部规则测试，不套用正式季的最低人数规则。工期需按团队、美术规格和实际制作速度另行估算，不以内容数量直接承诺发布日期。

### 12.2 实施工作包与依赖

1. 基础层：时钟、随机流、存档、配置表和事件总线。
2. 场景层：导航、设施容量、库存、预约与保障机制，依赖基础层。
3. 人物层：需求、效用选择、目标、认知与关系，依赖场景层。
4. 事件与摄录层：裁定、事实日志、机位覆盖和素材生成，依赖人物层。
5. 剪辑与播出层：命题、素材槽、受众与评分，依赖素材结构稳定。
6. 经营层：账本、赞助、案件、失败恢复，依赖事件和播出接口。
7. 局外与内容层：招募、跨季记忆、MCN、解锁，依赖完整单季闭环。

每个工作包分别交付配置字段、运行逻辑、调试视图与可复现样例。可以先以静态占位数据搭建界面，但不能把占位结果误当成真实模拟验证。

### 12.3 验收与策略测试

| 测试 | 操作 | 通过标准 |
|---|---|---|
| 因果可读 | 相同种子只改一个设施位置 | 相遇机会变化可回溯，人物性格不被重写 |
| 事实隔离 | 对同一素材制作两种节目 | 岛上历史不变，公众印象与风险可不同 |
| 认知隔离 | 播出秘密但不开反馈渠道 | 留岛未知情人物不凭空采取知情行动 |
| 缺素材恢复 | 禁用部分机位、减少事件 | 可用低收益方案继续，不死锁 |
| 反复冲突 | 连续针对同一对人物 | 疲劳、合作与新鲜度产生可见代价 |
| 救援约束 | 尝试封路或耗尽补给 | 非法布局被阻止或保障介入，不循环刷收益 |
| 账本一致 | 重载播出/结案检查点 | 广告与赔付各入账一次，现金严格守恒 |
| 退出处理 | 主角中途退出 | 现有素材仍可用，未完成关系线有合理处理 |
| 跨季责任 | 有未结案件时提前收季 | 案件与债务被带入，不能清空风险 |
| 完整切片 | 新档完成3日并结算 | 无阻断、无负库存、无永久预约、无缺失引用 |
| 零素材 | 首日所有机位停用且采访被拒 | 选择停更，正常推进日期并结算费用，不生成虚假素材 |
| 悬念中断 | 悬念主角退出 | 用离岛事实收束承诺，重复悬置不刷奖励 |
| 多人中断 | 双人活动进行时一人救援 | 释放双方与设施预约，仅结算已完成节点 |
| 停播推进 | 停播后完成一次维护日 | 无节目收入，案件与经营日照常推进 |
| 无债务现金危机 | 现金耗尽且无银行贷款 | 工资/救援义务也可触发清算，不陷入无出口状态 |

平衡测试至少比较照顾关系、偏好冲突、频繁干预三种策略，在同一组种子与相近操作预算下记录现金、有效收视、信任、退场次数和未结案件。初始门槛：任一策略不能在全部五项上持续支配另外两种；若存在，优先修改收益来源和机会成本，不靠随机罚款压平。

试玩另记录玩家是否能说出一条关键事件的原因、一次剪辑的后果，以及下一天准备调整什么。若玩家只感到“点按钮等随机狗血”，即使数值平衡也不算核心体验通过。

## 十三 尚待原型验证的决策

最优先验证素材卡剪辑是否有足够选择深度、需求与关系是否能产生可读差异、三类观众是否形成不同经营路线。若这些不成立，暂缓MCN和新地图；扩展内容不能替代核心玩法。

第二优先验证每集3段是否造成重复劳动、6名嘉宾是否超过观察负担、7日是否足以形成关系积累。允许调减人数、天数与段落数，但所有接口保持一致。

最后验证局外收益是否让海岛经营失去意义，以及并购终局是否有足够主动决策。只有当新系统带来新的取舍而非单纯等待现金增长时才纳入正式范围。

## 十四 单日闭环推演样例

以下为一条可配置演示路径，不保证每次模拟产生相同故事。初始人物A重视公平，B急于完成任务，C想争取领导权，D倾向照顾他人。

| 阶段 | 玩家或系统动作 | 状态写入 | 下一环节使用 |
|---|---|---|---|
| 晨间布局 | 将公共餐台靠近水站，并保留两条可达路径 | 距离缩短、相遇概率提高，支付移位费 | 人物行动候选的移动成本 |
| 上午录制 | B尝试插队，A质问；B道歉后回队 | 事实事件、怨怼短升再降、B形成被质问记忆 | 固定机位获得起因、反应和道歉 |
| 下午录制 | D帮B完成任务，C组织共同晚餐 | 信任变化与新素材 | 玩家拥有冲突线和合作线的选择 |
| 剪辑 | 玩家省略道歉，把B包装为持续霸占资源 | 成片命题与未纠正偏差，不改变A和B已经和解的事实 | 冲突观众注意力可能增加，形成潜在案件证据 |
| 播出 | 分群评价，依完整度、新鲜度与留存结算V | 广告现金、公众对B的印象、叙事承诺 | 决定次日资金和节目目标 |
| 次日反馈 | 玩家选择公开真实弹幕卡，B得知被误导呈现 | B获得新认知，合作模块降低W | B可能拒访，降低下一集素材供给 |
| 后续处理 | 发布完整道歉镜头并支付成立案件费用 | 命题纠正、现金减少、案件结清 | 信任缓慢修复，私人关系按后续行为恢复 |

另一条可行路线是保留道歉与协作，把故事剪成“冲突后的修复”。它可能没有最高即时热度，但完整度、合作意愿和后续关系素材更好。两条路线的优劣由实际种子、观众结构、现金缓冲与赞助条件共同决定，不能预先规定永远谁赚得更多。
