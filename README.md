# 收视率暴君：荒岛恋综制作人

基于 Three.js 的本地单人制作人经营游戏原型。现已接入选角、空营地建设、NPC自主生活与互动、摄录、剪辑、播出、案件处理及跨季经营。场景、人物与行为规则为原创实现，不使用任天堂源码，也不声称完整复刻其AI或品质。

## 启动

需要 Node.js、npm 和支持 WebGPU / IndexedDB 且已开启硬件加速的现代 Chrome 或 Edge 浏览器。在本目录运行：

```powershell
npm ci
npm run dev
```

默认打开 http://127.0.0.1:5188；端口占用会报错，避免误开其他游戏。不要直接双击 index.html。正式构建及本地预览：

```powershell
npm run build
npm run preview
```

默认只监听本机。安装依赖需要网络；安装后游戏不依赖在线AI、远程模型或外部字体。当前主入口为 `src/game.js`，旧 `src/main.js` 是保留的生活展示版本，不代表首页当前玩法。

## 演出舞台与放映室

双击项目根目录的 `演出放映室.html`，点「定妆预览」可直接观看花见、炉边与占星室的动态定妆。返回后继续原剧情。放映室内也可在「背景 · 随剧情」「花见」「炉边」「占星室」之间切换。主游戏根据演出主题选择舞台，涉及岛上具体地点的镜头保留实景。

启动开发服务后，访问 `/?perf=hanami&t=2&still=1&seed=7` 可查看花见的可复现定帧，将 `hanami` 换成 `cabin` 或 `orb` 可查看另外两幕。去掉 `still=1` 可观察粒子和视差。三套环境画板为本次生成的原创素材，角色、表情、动作、脚影、灯光及后期由 Three.js 实时合成。

舞台配方校验命令为 `node tools/gen-data.mjs --stage --check`。盲评工具为 `qa/stage-blind-review.mjs`，拼板随机排列左右，映射单独保存，评审应先记录偏好再揭晓。

## 人物工作室

标题页点「捏出你的人物」，选角卡片点「编辑形象」，或在顶部打开「人物工作室」。支持编辑默认人物及创建最多60位独立角色，并复制、删除尚未参演或签约的自建人物。

- 「照片生成」支持上传单人正面照片，在本机比较16种脸型并拟合下颌和五官位置，识别微笑，采样肤色、唇色和发色，匹配头发轮廓与眼镜。先检查结果，再应用到草稿，可撤销并继续手调，保存后同步到岛上。照片及面部关键点不上传、不写入存档；不确定的发型与镜框给出候选，可选择或保留原样；衣服和身形保留。无需调用GPT或其他云端AI，仍使用本机专用识别模型。首次识别会从游戏同源加载分割模型（约53MB）与运行时，较后续操作慢。建议使用无遮挡、光线均匀、睁眼平视的照片（PNG/JPEG/WebP，8MB/4096像素以内）；多人照需先裁剪。该功能是参数化卡通匹配，不是三维扫描或身份识别。
- 都市叙事、异星手绘、夸张喜剧三种造型方向；WebGPU 节点材质的分层明暗、轮廓描边与成人身段。
- 16脸型、76眼型、43眉型、32鼻型、53嘴型、58镜框（计数包含隐藏项）；保留18套旧发型，新增96前发与114后发剪裁，可独立组合、双色和镜像。前后发分别由16/19个母型各6种几何剪裁组成，不等于210个独立手工原型。独立耳型、睫毛、眼褶、高光、上下皱纹、雀斑、痣、妆容以及上唇胡/下巴胡/胡茬层，支持组件名称搜索。眉毛宽厚、镜框大小/高低/粗细和镜片、痣位置均可调，保留异色瞳、体型、6类服装及自由彩绘。12组原创灵感角色可继续编辑。来源及计数口径见 `qa/AVATAR_COMPONENT_REFERENCE.md`。
- 正面/侧面/背面/全身 WebGPU 预览，拖动旋转和滚轮缩放；6套原创搭配可继续修改。
- 自由面部彩绘、橡皮、镜像、星星/爱心/雀斑印章；可隐藏基础眼嘴绘制自己的脸。最多300笔、每笔2000点、合计30000点，文件最大2MB。
- 本地参考图（PNG/JPEG/WebP，8MB及4096像素以内）、撤销/重做、保存/放弃修改、角色JSON导入导出。参考图仅辅助观察，不会自动生成模型或保存进人物。
- 预览和岛上使用同一模型生成器；保存同步更新选角头像与演员，保留NPC关系、需求、位置和经营进度。编辑期间暂停录制，退出恢复原来的暂停状态。

人物库随本浏览器保存；每次重新打开或刷新游戏都会从标题页开始，清除经营、选角、设施、NPC经历与节目进度，但保留已保存的人物和外观。清算重开也保留创作但不继承经营资金。建议通过「导出角色」备份。JSON不是任天堂Mii/VRM文件，本项目没有导入这两类文件的功能。技术选择与四个参考仓库的源码研究见 `qa/AVATAR_TECHNICAL_DECISION.md`；目前不宣称与原作逐项1:1等同。

### 动漫精调与参考对照

- 要查看新版赤发环瞳造型：打开「人物工作室」→「角色研究」→「金环赤发」。建议先新建或复制人物再应用；旧人物不会自动覆写，保存后才更新岛上的角色。
- 在「眼睛」使用「自由曲线眼」，直接调整六个眼角／眼睑控制点，也可使用键盘微调；编辑器、实际眼白和虹膜裁剪共用曲线约束。支持撤销、重做与保存。
- 本地参考图可等比缩放、平移、旋转，使用透明叠图和灰度对照。对齐瞳距后检查脸型、五官和发型，不以颜色或角色名称代替相似度。参考仅留在当前编辑界面，不上传、不进入人物存档，也不是自动三维重建。
- **最新限定结论（2026-11-13）：** 第12轮“金环赤发”通过独立的可见正面主要结构验收；第8—11轮退回记录完整保留。不是像素级或任意角色精确复刻。
- **验收不等于测试通过。** 赤发环瞳造型经过多轮实现／独立审查；局部迭代与失败证据见 `qa/ANIME_INDEPENDENT_VISUAL_REVIEW.md`；完整参考的第二独立审计见 `qa/ANIME_FINAL_HOLISTIC_AUDIT.md`（按轮次追加，以最后一轮结论为准）。实现与开源分析见 `qa/AVATAR_ANIME_REDESIGN_REVIEW.md`。其余参考没有逐一完成同精度校准；单张倾斜、模糊的参考也不能认证未知侧面的精确还原。
## 一季怎样玩

1. **接下委托、签约选角。** 教学季4人3日，标准季6人7日。从12位默认候选及自建角色中选人；进阶人物有经验门槛，签约前要预留建设及运营现金。调查能揭示固定隐藏诉求。
2. **从空营地布置。** 购置水站、餐台、营地和机位；可付费委托基础布局，也可自行落点。移动、拆除、补给、检修都有成本，路线和服务席位影响嘉宾活动。公开水站规则可安排轮流、优先与食物奖励。
3. **自由录制，自己决定何时收工。** 开机后嘉宾自由生活，上午→下午→晚间→深夜自动推进，不会暂停或打断进行中的互动；素材足够时点「收工，进入剪辑」。嘉宾之间的相识和关系跨时段、跨天保留，不会每次开拍重新认识。观察人物的需求、关系和事件；导演每天3点额度。介绍、采访、内应与其他干预可以被拒绝。事件确实发生且被机位覆盖才形成素材，独处区限制摄录。录制暂停时可调整场地、补给和公开规则。
4. **剪辑与试映。** 每段选2至4张素材，正常节目需要3段且有共同主角。卡片可重排、选择叙事命题、配乐方向和历史回顾。可先生成草稿再修改；静帧和现场文字保留源事件，编辑不会回写岛上事实。未完待续可查看原语境与待兑现/已兑现/已过期状态；中断交谈可能在当日或次日真实续谈，也可能被拒绝。只有关联原场次的实际结果才能兑现悬念。可选商业委托提供达标奖金，不达标不扣罚。
5. **锁片播出与承担后果。** 正常、单段补救、零素材停更均可结算；补救广告按40%，停更没有节目收入但有运营费用。观察受众、现金和投诉，提供真实语境、更正或赔付。严重误导可能停播整改，维护日仍推进义务。
6. **收季、成长、再开季。** 结算后可购买制作升级、经营MCN、解锁雪山或别墅、收购竞争者。艺人每季主业互斥，旧案件和长期人物记录不会在下一季自动消失。收购后仍需盈利整合；破产新档不继承旧资金或NPC状态。

雪山的暖炉覆盖、容量和电力决定环境危险；别墅强调隐私压力。人物可能拒绝任务、进入医务或离岛。晨间可预签最多两位替补，支付25%定金；预签及原嘉宾退出/医务均满一天后，再补余款入场。原事实和其他嘉宾经历保留；人数不足时也可补救或提前收季。

## 操作与保存

- 鼠标拖动环顾、滚轮缩放；界面提供人物聚焦、事件镜头、场地和导演操作。
- 选择设施后点击有效地面落点；Esc取消放置。绿色/红色预览表示位置是否合法。
- 录制时可暂停并选择1×、2×、4×速度；Space切换暂停。事件镜头可关闭，手动控制会临时接管。
- 暂停时安排的六类导演指令先扣预算与额度并进入持久队列，恢复后才真正发送；界面区分待发送、已发送、实际回执与取消。未发送就收工或收季会取消并退还对应预算及额度；已发送后被嘉宾拒绝不退款。本次打开期间保留待发送队列；刷新或重新打开会随本局进度一起重置，不会凭空生成采访素材。
- 录制不限时：时段到点只结算设施损耗、电力与应急补给，不会停机。收工时尚未完成的互动会中断，不会补造结果。
- 环境声需主动开启；剪辑试映可试听所选配乐方向的程序音色。不是完整电影配乐或音视频成片播放器。
- 每次重新打开、刷新或从浏览器历史缓存返回游戏，都清除上一局进度，从第1季、第1天、¥100,000和初始海岛重新开始。已保存的人物及外观保留；不会恢复旧的NPC经历、拍摄素材或经营状态。本次打开期间每约8秒及成功操作后保存本机快照，用于保留人物库；再次打开不续玩该快照。后台不推进录制，没有离线收益。快照使用localStorage，素材静帧缓存使用IndexedDB；旧图片缓存不再关联新一局。清除站点数据会删除人物库及素材缓存；没有云端同步或多存档槽。
- 地址附加 `?qa` 可显示只读流程诊断。开发地址与preview地址属于不同浏览器存储来源，存档不会自动跨端口迁移。

## 当前限制

- 仍是持续开发的游戏原型，完整策划73项中有部分实现和待验证项，不能把按钮或数字齐全视为完整内容。
- NPC已有24类互动模板、双向每日冷却、需求、目标进度、关系和知情前提；有模板和前提测试不保证自然游玩频繁遇到每种稀有事件。完整恋爱生活、亲属、同居及长线叙事仍有限。
- 新素材在摄录资格判定通过后才截图归档；采访不能绕过隐私保护，旧版已存历史缓存未追溯清除。
- 素材是实拍静帧与文字事件；锁片后可按成片顺序进行定格放映，也可从收视结算回看。尚无完整连续视频回放、自定义字幕轨道或完整声音制作工作流。
- 岛屿可见区域大于可建设/可导航的生活区；人物并未实现全岛高差、过桥与任意室内导航。
- 三种地图已有独立场景和规则，但长线内容、所有地图整季体验、设备兼容与性能仍需扩大验证。
- 同种子策略对照已开展；现有报告仍存在策略被其他路线全面支配的情况，长期经济与干预价值未完成平衡。标准季目标时长及重复劳动也未完成验收。
- 存档有兼容校验与恢复副本，但完整损坏迁移矩阵尚未覆盖。IndexedDB不可用时事实与经营记录仍可保存，素材图片可能缺失。

照片发型匹配现比较实际模型生成的126种前发、156种后发轮廓，并包含“无额外刘海”的基础发冠候选。脸部拟合使用等比照片坐标；镜框匹配考虑脸部缩放后的实际比例，调整大小不再改变镜片中心。眉宽、可见露齿和不确定候选分别处理。真实自动匹配对照与已知限制见 `qa/PHOTO_MATCH_REVIEW.md`；匹配分数不代表人物身份相似度。
